# Bok! — Croatian learning

A local, browser-based Croatian learning game. It starts from absolute beginner level and includes a 6-section path with 60 short lessons.

## Open it

Open the project folder in File Explorer and double-click `index.html`. No server, account, or package install is required. Refresh the browser page after app files change.

Progress is saved in the browser's local storage. Use the same browser and keep the project in the same folder to continue where you left off.

## Included

- A progressive A1–C1 learning path with completed, current, and locked lessons
- Seven focused exercise formats in each lesson: vocabulary, translation, sentence building, fill-in, matching, grammar, and choosing the right phrase for a situation
- Croatian grammar and vocabulary practice, including special letters and the seven cases
- XP, levels, streaks, hearts, gems, unit rewards, daily quests, achievements, and a simulated offline league
- Flashcard reviews, heart-recovery practice, and optional profile cosmetics
- Responsive layout for desktop and phones

The weekly league uses clearly labelled simulated learners. Each lesson teaches its own practical phrase and vocabulary, and lessons build from greetings to introductions, directions, cafés, and everyday topics.
